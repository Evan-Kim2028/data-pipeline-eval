Partition overwrite wrote day=2026-08-01.

The read path then walked the whole bronze tree and mixed other
days into the result. Downstream rolled up a union of partitions
as if it were one day.

Daily totals for the 1st were inflated by every other partition
sitting in bronze. Analysts flagged the 1st as an outlier around
14:00. The write itself looked fine. The day file on disk has
only the 1st. The read is what mixed the rest in.
