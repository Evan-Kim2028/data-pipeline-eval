How to read this

More hops means the CoT broke into more claim/paragraph units. Longer hops means each unit is bigger. Tokens per hop is reasoning_tokens / hop_count. Think_s is stream time spent in the reasoning phase. Catalog very_hard does not predict hop load. Failures split by mode, not by host rank.
